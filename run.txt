# How to run the engine.
#
# Phase 1 (Phase 0 §2.1): this used to bind 0.0.0.0, which put an
# unauthenticated start/stop control plane on every interface. It now
# binds loopback by default.

# Local (default, safe):
uvicorn backend.main:app --host 127.0.0.1 --port 8000

# Dashboards:
#   http://127.0.0.1:8000/           live engine
#   http://127.0.0.1:8000/dashboard  Quant DB explorer

# Remote access: set API_TOKEN in .env FIRST, then bind wider.
# Without a token the API is open to anyone who can reach the port.
#   uvicorn backend.main:app --host 0.0.0.0 --port 8000
